# Git Workflow Mastery

A hands-on DevOps project demonstrating essential Git and GitHub workflows.

## Project Objectives

- Understand Git repository initialization
- Practice staging and atomic commits
- Create and manage feature branches
- Resolve merge conflicts
- Collaborate using GitHub Pull Requests
- Use Git tags, Issues, and Releases

## Technologies

- Git
- GitHub
- HTML
- CSS
- JavaScript

## Branching Strategy

This project uses a feature-branch workflow.

The main branch contains stable, reviewed changes.
New functionality is developed in separate feature branches
and integrated through Pull Requests.
